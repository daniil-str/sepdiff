# SEPDiff — правила работы

История правок статей Stanford Encyclopedia of Philosophy: краулер архивных
изданий, CLI и веб. Python 3.13, uv, FastAPI + Jinja2 + htmx, SQLite без ORM.

## Пять правил, которые важнее остального

1. **В `main` мёржит только владелец, на GitHub.** Работа идёт в ветке
   `task/<имя>`: закоммитил, запушил, открыл PR — и это уже отчёт на ревью,
   дальше жди. Напрямую в `main` не коммитим и не пушим никогда. Цикл задачи
   целиком — PLAN.md, раздел 2.
2. **`data/` не трогать.** Там снимки SEP: почти час краулинга по 5 секунд на
   запрос, единственная копия, в git не попадает (копирайт). Не удалять и не
   чистить; для экспериментов — свой каталог через `$SEPDIFF_DATA`.
3. **Сеть — осознанно.** Один запрос в 5 секунд; `/cgi-bin/`, `/diffs/`,
   `/search/`, `/rss/`, `/perl/` запрещены robots.txt; plato.stanford.edu с
   этой машины доступен только через прокси `HTTPS_PROXY=http://127.0.0.1:2080`.
   Тесты в сеть не ходят никогда, уже скачанное архивное издание не
   перекачивается никогда.
4. **Меняешь разбор HTML — подними `EXTRACT_VERSION`** (`extract.py`); меняешь
   схему БД — подними `SCHEMA_VERSION` и добавь запись в `MIGRATIONS`
   (`db.py`). Иначе данные тихо разъедутся с кодом.
5. **Классификацию правок меняй только против эталона** (`tests/archinfo.py`,
   `tests/test_real_snapshots.py`): сейчас находятся 120 из 125 правок,
   записанных самим SEP. Стало меньше — это регрессия, а не новый эталон.
